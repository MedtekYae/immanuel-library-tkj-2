1. Memisahkan header dan footer jadi komponen tersendiri bikin kodingan jauh lebih rapi dan efisien. Kalau misal ada perubahan di menu atau tampilan footer, kita cuma perlu edit di satu file aja tanpa harus ngedit manual satu-satu di setiap halaman. Selain itu, hal ini juga mencegah terjadinya kelewatan atau perbedaan tampilan antar halaman.
2. Masalah yang sama terjadi di bagian sidebar dan topbar navigasi admin. Sebelum dipisah jadi komponen tersendiri, struktur HTML sidebar dan topbar ditulis ulang secara berulang di setiap file halaman admin. Akibatnya, kalau ada penambahan menu baru, kita harus ngubah isi kode di semua file halaman admin satu per satu.
